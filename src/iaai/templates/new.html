Что нужно установить в ходе исследования

Это конкретные параметры или вопросы, по которым система должна собрать доказательства. Они не являются оценкой идеи. На этом этапе мы только сохраняем их.

Пишите обычными словами. Например: время работы от батареи, диапазон цены, стоимость ремонта, гарантийные условия, существующие альтернативы, данные о готовности покупателей платить. Добавьте хотя бы одну строку здесь или в расширенных настройках.

Расширенные настройки показателей

Необязательно. Для числового показателя можно дополнительно задать внутреннее имя, тип, единицу и описание. Каждая строка здесь добавляет отдельный показатель к обычному списку.

Пример: prototype_cost|number|EUR|Стоимость прототипа — выяснить стоимость в евро, без оценки «дорого/дёшево». Типы: number (число), text (текст). Одно техническое имя без разделителей создаёт текстовый показатель.

Внутренние имена уникальны: латинские буквы, цифры, точка, дефис, подчёркивание. Единицы: EUR, USD, AUD, GBP, bytes, seconds, hours, days, kg, g, mm, cm, m, W, Wh, percent, count, ratio, text. Автоматического перевода единиц нет.

Явные ограничения

Ограничение — это не мнение IAAI о том, что хорошо или плохо. Это явно заданная граница, например: «бюджет первого прототипа не больше 20 000 EUR». Отсутствие ограничений — нормальное состояние.

Расширенные настройки / для разработчика

Обычно оставьте пустым. На текущем этапе сложные ограничения можно задать в JSON. Значение [] означает отсутствие ограничений.

Поля: output — имя показателя, type — происхождение, operator — сравнение, value — значение, unit — единица, origin — источник ограничения.

Типы: USER — пользователь; REGULATORY — нормативное требование; PHYSICAL — физическое; TECHNICAL — техническое; METHODOLOGICAL_EVALUATION — проверка методологии. Сравнения: eq — равно; lt — меньше; le — не больше; gt — больше; ge — не меньше.

Пример только для явно заданного бюджета и показателя prototype_cost выше:

[{"output":"prototype_cost","type":"USER","operator":"le","value":20000,"unit":"EUR","origin":"Бюджет задан пользователем"}]
